# Upstream integration map

Source review: September 28–29, 2026. All **46 requested repositories** were checked through GitHub metadata, recursive trees, README/license, and representative implementation/manifests/test or CI files. Seven successors/alternatives received the same source sampling; two additional 2026 research candidates received README/license review. This is an architecture/source sampling review, not an exhaustive security audit or reproduction of every upstream test. Sources are linked to inspected short commit IDs where available. Commit dates measure activity, not support guarantees. Upstream CI definitions were read, not run by us.

Decision vocabulary: **USE DIRECTLY**, **USE THROUGH ADAPTER**, **PORT SMALL COMPONENT**, **REIMPLEMENT THE IDEA**, **RESEARCH REFERENCE ONLY**, **REJECT**. Below, `Adapter` means USE THROUGH ADAPTER, `Idea` means REIMPLEMENT THE IDEA, `Reference` means RESEARCH REFERENCE ONLY, and `Reject` means REJECT. No third-party implementation is copied/ported. **Only the optional Ollama HTTP adapter is implemented in this slice.** All other adapters are future candidates behind explicit gates; none is added to requirements. Existing Python stdlib SQLite is used directly.

## Licensing and integration gates

MIT/BSD notices must accompany redistributed code; Apache requires license/notice handling and modification notices where applicable. GPL/AGPL components can impose source/distribution or network-use obligations; process separation is not asserted to erase them. Commercial/source-available and mixed-license trees require artifact-specific review. Model weights, datasets, browser binaries and transitive dependencies have their own terms. This review makes **no legal compatibility guarantee** for a future commercial bundle. No upstream source or weights are copied in this PR.

Before any candidate becomes a dependency: pin artifact and hash, read its actual license and dependency licenses, measure cold start/RSS/CPU/p95 on the applicable environment, run contract/negative tests through the kernel, verify offline behavior, document update ownership and prove removal/export path. Failure of any gate keeps it optional/disabled. The current source evidence does not establish that a newer complete agent platform is superior to preserving this repository's tested boundaries.
